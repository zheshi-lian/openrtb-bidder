程序化广告平台演示 · DSP + SSP + 实时竞价引擎

本平台 = DSP + SSP + 实时竞价引擎，聚合长尾 App 流量，连接广告需求与媒体供给。商业模式：开发者侧聚合长尾流量（App 开发者的广告位，6 种形态呈现），广告主侧投放买量；另有外部需求方（DSP）接入：把其他买方的 OpenRTB 出价端点接入本平台拍卖来买我们的流量（示例见「外部 DSP 接入」页）。盈利 = 投放差价 + 技术服务费。① 广告形式（6 种形态，可对照 rewarded 参考实现）；② 外部需求方(DSP)接入：注册 OpenRTB 出价端点参与拍卖；③ 风控/可见性。

② 外部需求方(DSP)接入 高级 / 商务对接

把外部买方（其他 DSP、广告网络、或代理商自有竞价端）的 OpenRTB 出价端点注册进本平台拍卖， 它就会在每次竞价时收到我们的 bid request 并出价，买走开发者（媒体）的广告位。 这里我们是卖方，注册进来的是买方。
买方越多 → 竞争越充分 → 开发者 eCPM 越高 → 平台毛利越高。真实需求方对接属商务动作， 操作入口见 「外部 DSP 接入」。
注意方向：代理去外部平台（短视频 / 社交平台等）花钱投放是相反方向（我们是买方）， 由投放中台处理，不在本平台范围内。
