平台核心能力架构

对标 AppLovin / 汇量 Mintegral 的真实落地模块（均非 PPT）：流量侧与需求侧在交易所内实时撮合，所有结果回流到数据飞轮。

CAP 01

双向 OpenRTB 实时竞价

自有 DSP 出价引擎 + SSP 多需求方二价清算（second-price），媒体分成透明、可审计。

CAP 02

全链路归因与增量度量

多触点归因、SKAN 视图归因，holdout / ghost ads / geo-lift 增量实验，证明广告「真的有效」（对标 Adjust）。

CAP 03

创意自动化工厂

可玩广告、DCO 元素级组合、文生图 / 图生视频、多语言本地化（对标 Mindworks / Spark）。

CAP 04

ESMM 多目标预估 + 智能出价

CTR/CVR 多任务模型（pCTCVR = pCTR·pCVR 规避样本选择偏差）+ pLTV 多目标 + bid shading + eCPM′ 贝叶斯冷启动（对标 AXON 内核）。

CAP 05

增长 Agent + 数据飞轮

读懂 Brief → 生成创意 → 真实建 campaign 参拍 → 读实测 eCPM/eCPA → 回流重训模型，闭环自进化（领先于竞品的智能体编排层）。

CAP 06

合规与品牌安全基线

IAB/GARM 品牌安全、post-ATT 设备身份图谱、ads.txt / app-ads.txt / sellers.json 校验。

第一性原理：广告平台的本质是「撮合 + 数据飞轮」——平台赚的是广告主 eCPM 与给媒体 payout 之间的差价；真正的护城河是模型预测的 ROI 比对手更准。模型越准 → 广告主 ROI 越高 → 预算越多 → 数据越厚 → 模型更准，飞轮一旦转起来后来者很难追（这也是 AppLovin / 汇量把 AI 引擎当核心资产的原因）。

3 步接入

全部自助完成，无需销售介入。开发者 5 分钟拿到广告位代码，广告主提交开户后进入审核（未通过审核不产生任何扣费）。

STEP 01

开发者取密钥

填写域名，立即拿到 api_key，随后可在后台创建广告单元并拿到埋点代码；落地页会被合规爬取补全品类/地域，自动抬升 eCPM。

STEP 02

广告主开户

提交开户信息（登录用户名 / 密码 / 广告主名称），生成待审计划；运营审核 + 充值后即可参拍。或 注册你的 OpenRTB 端点 作为 DSP。
