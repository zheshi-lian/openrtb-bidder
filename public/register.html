自助注册

广告主自助投放：只需邮箱与密码即可开通，推广目标、网站、支付与合规信息均可在后台按需补全，不阻塞投放。

广告主（买量）、开发者（变现）、平台运营是三套互相独立的账号体系：账号、数据与结算各自隔离，不会互看。

广告主开户后自动获得：
  • 广告主后台账号与 API Key
  • 一套示例素材（可立即绑定投放）
  • 推广目标、网站、支付方式可后续补全
开发者 / 媒体入驻后自动获得：
  • 媒体后台账号（登录=邮箱）
  • api_key 与广告位埋点代码（SDK 接入用）
  • 收款 / 税务 / 域名验证可在后台补全
用 API 直接调用 POST /api/account/register-admin 时，邀请码字段 code 或 invite_code 均可，登录名字段 username 或 email 均可（后端已做别名兼容，页面 hint 与文档不会再对不上）。
平台运营管理员：
  • 凭一次性邀请码自助开通独立管理员账号（各自强密码 + 可开 2FA）
  • 开通后请立即开启两步验证，并妥善保管账号
  • 管理员看不到广告主 / 媒体的商业数据，仅做审核、看数、结算与接入管控
