推荐新接入的媒体方使用 AdView.kt（单文件、无外部依赖、支持 banner/interstitial/splash/icon/rewarded/native/push 全形态，激励视频走 S2S 发奖）；已有激励视频接入的媒体方可继续使用 RewardedAdSdk.kt。
需要 AAR（预编译包）？直接用现成包接入最快：下载 applink-adsdk-release.aar（包名 com.zhuque.adsdk，零第三方依赖）。放入宿主工程 app/libs/ 后依赖 implementation fileTree(dir: 'libs', include: ['*.aar']) 即可。
持续集成会自动出包：仓库 Actions 每次 push 产出 Artifacts，打 v* tag 自动发布到 Releases（始终是最新可用包）。也可源码工程本地构建：./gradlew assembleRelease，产物在 build/outputs/aar/applink-adsdk-release.aar。工程含 build.gradle、README（集成文档）、混淆规则；权限已在 src/main/AndroidManifest.xml 声明（INTERNET / ACCESS_NETWORK_STATE）。

② 支持的广告形态

  • 激励视频 rewarded：VAST 4.0 视频，完播后 S2S 发奖
  • 插屏 interstitial / 开屏 splash：WebView(HTML) 渲染
  • 原生 native：返回结构化 JSON，由 App 自渲染样式
  • icon / push：推送系统下发，不经 SDK 渲染

1) 将 RewardedAdSdk.swift 加入 Xcode 工程；2) 在需要展示的位置调用：

import UIKit
let cfg = RewardedAdSdk.Config(
    adxBase: "https://你的平台域名",         // 留空默认 dellai.xyz
    siteDomain: "你的媒体域名",              // 须与平台注册一致
    appServerRewardUrl: "https://你的服务端/reward")  // S2S 回调

RewardedAdSdk.shared.load(cfg: cfg, keywords: "休闲游戏,激励视频") { result in
    switch result {
    case .success(let ad):
        RewardedAdSdk.shared.show(from: self, ad: ad) { granted, reward in
            granted ? print("发奖:", reward) : print("拒绝:", reward)
        }
    case .failure(let e): print("加载失败", e)
    }
}

1) 将 AdView.kt 加入工程（包名 com.zhuque.adsdk）；2) 在布局中放一个 AdView；3) 调用三个 load 方法：

val adView = AdView(this)
adView.adUnitId = "首页-banner"
adView.siteDomain = "你的媒体域名"
adView.adxBase = "https://你的平台域名"
adView.appServerRewardUrl = "https://你的服务端/reward"  // S2S 发奖回调（仅 rewarded 需要）

// Banner（信息流内嵌 / 底部横幅）
adView.loadBanner({ ad -> adView.setBannerHtml(ad.html) },
                  { reason -> Log.w("Ad", "banner: $reason") })

// Interstitial（全屏插屏）
adView.loadInterstitial({ ad ->
    activity?.addContentView(adView.showInterstitial(ad.html),
        ViewGroup.LayoutParams(ViewGroup.LayoutParams.MATCH_PARENT,
                              ViewGroup.LayoutParams.MATCH_PARENT))
}, { reason -> Log.w("Ad", "interstitial: $reason") })

// Rewarded（激励视频，VideoView 播放 VAST 4.0；完播后由 appServerRewardUrl S2S 发奖）
adView.loadRewarded({ ad ->
    adView.playRewarded(videoView, ad) { reward -> /* 发奖 */ }
}, { reason -> Log.w("Ad", "rewarded: $reason") })

// Native（结构化 JSON，由 App 自渲染样式）
adView.loadNative({ ad -> renderMyOwn(ad.nativeJson) },
                  { reason -> Log.w("Ad", "native: $reason") })

旧版（仅激励视频）仍可用 RewardedAdSdk.kt：

val cfg = RewardedAdSdk.Config(adxBase = "https://你的平台域名",
    siteDomain = "你的媒体域名", appServerRewardUrl = "https://你的服务端/reward")
RewardedAdSdk.load(cfg, "休闲游戏,激励视频", object : RewardedAdSdk.LoadCallback {
    override fun onLoaded(ad: RewardedAdSdk.Ad) {
        RewardedAdSdk.show(videoView, ad, object : RewardedAdSdk.RewardCallback {
            override fun onGranted(reward: String) { /* 发道具 */ }
            override fun onDenied(reason: String) { /* 不给 */ }
        })
    }
    override fun onFailed(reason: String) {}
})

SDK 不会自己发奖。App 服务端收到观看证据后，用 api_key 做 HMAC-SHA256 签名， 再回调平台 POST /s2s/reward，由平台裁决是否发奖：

// 请求体
{ "impid": "...", "cid": "...", "publisher": "...",
  "watchedMs": 30000, "durationMs": 30000, "ts": 1690000000000, "sig": "HMAC_SHA256(...)" }

// sig = HMAC_SHA256(api_key, "impid|cid|watchedMs|durationMs|ts")
// 平台返回 { ok:true, reward:"金币x100" } 或 { ok:false, reason:"RATIO_LOW" }

平台侧校验：完播率 ≥ RW_MIN_RATIO(0.95) 且观看时长不超过视频 1.5 倍，否则拒绝发奖（防伪造刷量）。
