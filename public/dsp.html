外部 DSP 接入（买我们的流量）

AppLink 既是 SSP 也是 Exchange。外部买方可以标准 OpenRTB 2.x 接入，与自有 DSP 一同参拍（二价清算）。

接入步骤

  1. 在「① 出价端点注册」下方直接填写并提交，即可把你的出价端点注册进来（外部 DSP 不创建平台账号、不登录后台）。
  2. 平台分配 DSP 标识，并将你的端点登记进竞价参与方列表。
  3. 你的服务端实现对 POST /openrtb2/bid 的 OpenRTB 2.6 响应（返回 seatbid / bid / price）。
  4. 平台在 SSP 拍卖中把你的报价与自有 DSP、其他需求方一并二价清算；赢价后通过 /notify 回传计费。

① 出价端点注册

请求示例（供给侧发起的竞价请求）：

{ id, imp:[{id,banner:{w,h},bidfloor}], site:{domain}, device:{ua,ip}, at:2, tmax:3000 }

所有接口均为真实实现，可用 Prebid 端到端演示 当场验证。
